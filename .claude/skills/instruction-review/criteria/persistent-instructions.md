# Persistent instruction criteria

Apply alongside [shared criteria](shared.md). These files provide scoped
context; they are distinct from configured agent definitions.

## Loading and scope

Establish how the intended host loads the file, including directory scope,
inheritance, imports, and precedence. Check overlapping instructions against
those rules rather than assuming every host treats AGENTS.md and CLAUDE.md
alike.

## Persistent-context value

Does always-loaded content apply broadly enough to justify its placement? Favor
project-specific commands, constraints, nonstandard practices, and recurring
pitfalls. Suggest selective references for conditional workflows when they
reduce routine context without hiding essential requirements.

## Project accuracy

Check consequential paths, commands, and architectural claims against available
project evidence. Flag stale guidance with a concrete consequence. An unfamiliar
convention or a missing preferred section is not itself a defect.
